# AGENTS.md

Guidance for AI coding agents working on this repo. For humans, see README.md.

This is a NixOS flake describing all of Zoe's machines. It is checked out at
`/etc/nixos` on each machine and is a **public** GitHub repo
(`zoeleu/nixos`), so everything committed is visible to anyone.

## Layout

```
flake.nix               # every directory in hosts/ becomes nixosConfigurations.<dir>
modules/common.nix      # system settings shared by all hosts
modules/ci.nix          # ci.heavyPackages option (slow packages CI builds in parallel)
home/common.nix         # zoe's Home Manager config shared by all hosts
hosts/<name>/default.nix               # per-machine config; hostname = <name>
hosts/<name>/hardware-configuration.nix  # generated by nixos-generate-config, don't hand-edit
ci/unfree-names.nix     # lists a host's unfree packages (kept out of the public cache)
ci/push-built.sh        # pushes packages to Cachix as soon as they're built
.github/workflows/build.yml   # prepare -> heavy (parallel) -> build -> weekly commit
.github/actions/{setup,finish-push}/  # shared CI steps
```

Hosts:
- `deck`: Steam Deck LCD running Jovian NixOS. Separate auto-login `deck`
  user for Gaming Mode, `zoe` is the admin with an fscrypt-encrypted home.
- A `desktop` host is planned (fresh install with LUKS, auto-login into zoe,
  key-only SSH). It doesn't exist yet; don't invent its hardware config.

## Where things go

- Shared by every machine: `modules/common.nix` (system) or
  `home/common.nix` (zoe's dotfiles/apps via Home Manager).
- One machine only: `hosts/<name>/default.nix`.
- Keep host-specific policy out of `common.nix`. SSH auth rules, auto-login,
  fscrypt, desktop environment, kernel and `nix.settings.max-jobs` are
  per host on purpose.
- New flake inputs: add `inputs.nixpkgs.follows = "nixpkgs"` when the input
  has a nixpkgs input. Modules get `inputs` through `specialArgs`.
- A slow-to-compile package for one host: add it to `ci.heavyPackages` in
  that host's `default.nix`. Kernel, graphics drivers and PipeWire are
  already added for every host by `modules/ci.nix`.

## Verify changes before committing

There is no test suite; evaluating every host is the test. Nix only sees
files tracked by git, so `git add` new files first.

```bash
export NIX_CONFIG="experimental-features = nix-command flakes"
nix eval --json .#nixosConfigurations --apply builtins.attrNames          # hosts
nix eval --raw .#nixosConfigurations.<host>.config.system.build.toplevel.drvPath   # must succeed for every host
nix build --dry-run .#nixosConfigurations.<host>.config.system.build.toplevel      # what would compile
HOST=<host> nix eval --impure --raw --file ci/unfree-names.nix 2>&1 >/dev/null | sed -n 's/^trace: UNFREE //p' | sort -u
nix run nixpkgs#actionlint -- -ignore SC2016 .github/workflows/build.yml  # after editing CI
nix run nixpkgs#shellcheck -- ci/push-built.sh
```

Don't run `nixos-rebuild switch` on someone's machine as a way of testing;
evaluate instead, and leave applying to Zoe.

## Rules

- **No secrets in the repo.** It's public. Passwords, tokens, wifi
  passwords and private keys must never be committed. Public SSH keys are
  fine. If a secret is needed, ask first; the plan is sops-nix.
- **Never upload unfree packages to Cachix.** The cache
  (`zoeleu.cachix.org`) is public; Steam, claude-code etc. can't be
  redistributed. Keep the unfree filtering in `ci/` and
  `.github/actions/` intact: a package is skipped if anything in its
  closure is unfree (cachix pushes closures).
- **Don't run `nix flake update` locally.** CI updates `flake.lock` weekly
  and commits it only after every host built, so machines download instead
  of compiling. Change `flake.lock` only when adding or removing an input.
- **Never change `system.stateVersion` or `home.stateVersion`.** They
  record each machine's first install.
- **Deck: never reset zoe's password as root** (`sudo passwd zoe`, or
  setting `hashedPassword`/`initialPassword` for zoe). Her home is fscrypt
  encrypted with only her login password as key and no recovery passphrase,
  so a root reset locks it permanently.
- **Deck: Jovian owns the display manager.** `jovian.steam.autoStart` turns
  on SDDM with auto-login itself. Don't enable another display manager or
  disable SDDM. Don't override `boot.kernelPackages` on the Deck: Jovian
  sets Valve's kernel.
- Keep 2 builds × 4 cores on the Deck (`nix.settings.max-jobs`/`cores`);
  more makes it swap.
- `hardware-configuration.nix` files come from `nixos-generate-config` on
  the real machine. Don't write or "fix" them by hand.

## Commits

- Message style: `scope: short summary` (e.g. `ci: ...`, `deck: ...`,
  `cache: ...`), body explaining what and why.
- Commits are SSH-signed; keep signing on.
- Every push to `main` starts a full CI run and **cancels the one in
  progress**. For changes that don't affect any build (docs like this
  file), put `[skip ci]` in the commit message.
